# Miss 5ème — Guide rapide

> **Statut : historique / activation à vérifier.** Aucun identifiant, mot de passe ou PIN n’est documenté ici.

## Pour un juré

1. se connecter avec son compte PMM individuel ;
2. ouvrir le concours auquel il est affecté ;
3. choisir le passage actif ;
4. sélectionner une candidate ;
5. renseigner les critères affichés ;
6. vérifier le total/récapitulatif ;
7. valider la note ;
8. contrôler la confirmation d’enregistrement.

## Pour l’administrateur

1. configurer le concours ;
2. ajouter les candidates ;
3. affecter les jurés ;
4. vérifier critères et barèmes ;
5. ouvrir la notation ;
6. surveiller les fiches manquantes ;
7. clôturer les passages ;
8. contrôler le classement avant publication.

## Règles essentielles

- un compte par juré ;
- authentification Neon Auth ;
- aucune confiance accordée à une simple valeur navigateur ;
- contrôle des permissions côté serveur ;
- aucune note hors barème ;
- pas de double notation active pour le même juré/candidate/passage/critère ;
- toute correction admin doit être tracée ;
- les résultats restent privés avant publication officielle.

## Dépannage

En cas de note absente ou d’erreur : ne pas ressaisir en boucle. Vérifier d’abord si l’enregistrement existe, puis transmettre à l’administration la candidate, le passage et le message affiché — jamais les informations de connexion.
